# Published query workloads

[published-workloads.json](published-workloads.json) records the query sources, fixed train/dev/test splits, and SHA-256 checksums for arXiv, Spider, Wikipedia, and YFCC1920. The reproduction runner uses these inputs as published. Four Wikipedia source queries are outside the experiment splits.

See the [main README](../README.md) for the external databases, vectors, indexes, and encoder services required by the comparison.
